# 메이플레코드 바

메이플 화면 위에 붙는 작은 바로 [메이플레코드](https://maple-record.vercel.app)를 쓰는 Windows 프로그램이에요.
브라우저를 오가지 않고, 게임 위에서 보스 · 사냥 측정을 켜고 기록을 봐요.

## 내려받기

**[최신 버전 내려받기 (MapleRecordBar.exe)](https://github.com/Kong1199/maple-record-bar/releases/latest/download/MapleRecordBar.exe)**

지난 버전과 바뀐 내용은 [Releases](https://github.com/Kong1199/maple-record-bar/releases)에서 볼 수 있어요.

## 할 수 있는 것

- **게임 위의 바**: 메이플 화면 위쪽 끝에 마우스를 대면 바가 나와요. 눌러도 게임 창이 뒤로 가지 않아요.
- **보스 · 사냥 바로 측정**: [보스] · [사냥]을 누르면 메이플 창을 고르는 단계 없이 바로 화면을 공유해 측정해요. 측정 중에 다시 누르면 멈추고 기록해요.
- **게임 위에 떠 있는 창**: 메이플레코드 · 사냥 작은 창 · 웹툰 · 인터넷 창. 창마다 투명도를 조절하고, 닫아도 보던 화면이 남아요.
- **환산주스탯 · 인벤 바로가기**: 메이플 스카우터의 분석 · 최적화 메뉴, 메이플 인벤 자유게시판 · 팁과 노하우(10추 · 30추).
- **키로 넘기기**: 게임을 하면서 정해 둔 키로 웹툰 · 인터넷 창을 넘겨요.
- **메이플과 같이 꺼짐**: 메이플을 끄면 바도 같이 꺼져요 (측정 중이면 먼저 멈추고 사냥을 기록해요 · ⚙ 에서 끌 수 있어요).
- **알림은 사이트 그대로**: 극딜 · 룬 · 도핑 · 부스터 · 정령의 펜던트 알림과 소리가 메이플레코드 사이트와 똑같이 울려요.

자세한 사용 방법은 메이플레코드 사이트의 [가이드] → [메이플레코드 바]에 그림과 함께 있어요.

## 필요한 것

- Windows 10 또는 11 (64비트)
- [.NET 8 데스크톱 런타임 (x64)](https://dotnet.microsoft.com/ko-kr/download/dotnet/8.0) — 없으면 프로그램을 켤 때 받으라는 창이 떠요
- Microsoft Edge WebView2 런타임 — Windows 11 에는 들어 있고, Windows 10 도 대부분 이미 깔려 있어요
- 메이플스토리는 창 모드나 테두리 없는 창 모드로 (전체 화면 전용 모드에서는 바 · 창이 게임 위에 안 보여요)

## 설치 · 실행

1. 위 링크로 `MapleRecordBar.exe` 파일 하나를 받아요. 설치 과정이 따로 없으니 원하는 폴더에 두면 돼요.
2. 서명이 없는 개인 프로그램이라 Windows 가 'PC 보호' 창을 띄울 수 있어요. **[추가 정보] → [실행]**을 누르면 켜져요.
3. 켤 때 관리자 권한을 묻는 창이 떠요. **[예]**를 누르면 게임 중에도 넘기기 키가 돼요. [아니요]를 눌러도 켜지고, 그때는 게임 중 넘기기 키만 안 돼요.
4. 프로그램 안의 메이플레코드는 브라우저와 따로라서, 처음 한 번 카카오로 로그인하거나 [로그인 없이 사용하기]를 골라요.

지우려면 `MapleRecordBar.exe` 를 지우면 돼요. 설정 · 로그인 정보까지 지우려면 `%AppData%\MapleRecordBar` 와 `%LocalAppData%\MapleRecordBar` 폴더도 지워요.

## 하는 일 · 하지 않는 일

| 하는 일 | 하지 않는 일 |
|---|---|
| 메이플 창의 위치를 보고 그 위에 바를 띄워요 | 게임에 키 · 마우스를 대신 보내지 않아요 (자동 사냥 · 매크로 없음) |
| 화면 공유로 게임 화면을 '보기만' 해요 (사이트와 같은 방식 · 이 컴퓨터 안에서만 분석) | 게임 메모리 · 파일 · 통신을 읽거나 고치지 않아요 |
| 넘기기 키가 눌렸는지 '읽기만' 해요 | 게임 화면이나 기록을 다른 곳으로 보내지 않아요 |

넥슨이 만들거나 확인한 프로그램이 아니에요. 게임을 건드리지 않게 만들었지만 운영정책상 문제가 없다고 보장할 수는 없으니, 쓰는 건 본인 판단으로 해 주세요.
